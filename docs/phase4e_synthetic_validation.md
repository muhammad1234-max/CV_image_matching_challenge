# Adversarial validation

Eleven parametrized tests cover exact and broken triangles, disjoint observations on an image triangle, contradictory indices in a component, missing links, sparse and unequal support, duplicate records, reversed orientation, invalid indices, a 128-spoke hub, degenerate coordinates and equivalent image/index renaming. The repeated-texture fixture intentionally produces a perfectly consistent false track. Missing links cannot establish inconsistency. Unit tests establish counting semantics rather than physical correspondence correctness.
