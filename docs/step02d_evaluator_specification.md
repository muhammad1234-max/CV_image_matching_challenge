Current verification used Python 3.13.7, NumPy 2.1.2; pin the actual Phase 3 Linux environment before running comparisons.

Primary assignment maximizes camera overlap first, mAA second (`np.lexsort` last key is primary). Sensitivity changes only that selection line in memory to maximize mAA, then overlap/cluster-size purity, then original cluster index. The adapter itself is hash-pinned in the draft manifest. This is a documented interpretation of written prose, not a claim of hidden scorer equivalence. All-zero/degenerate tie handling and cluster reuse remain participant behavior.

Camera centers are `-R.T @ t`. Horn registration searches finite predicted center triplets for similarity transforms (rotation, translation and scale); `inl_cf=0`, `strict_cf=-1` preserve exhaustive reference settings. Registration uses strict distance less-than threshold. Per-scene mAA subtracts three fitting cameras, floors numerator at zero, and divides by `(n-3)` across retained thresholds. Dataset mAA pools scene numerators and adjusted camera denominators. Clusterness is summed selected overlap divided by summed selected cluster sizes. Harmonic fusion is applied per dataset; overall score equally averages datasets. The adapter converts percentage outputs to fractions. It runs the reference three times to expose mAA, clusterness and harmonic components; account for this evaluation cost separately from inference/SfM.

All 30 decoded raw threshold strings and parsed vectors are pinned in `thresholds.json`. Three Haiper scenes retain `0;0;0.001;0.025;0.05;0.1`; six zeros are preserved. The original code skips the first two thresholds, leaving four positive thresholds. A synthetic perfect five-camera regression scores 1 with skip-two and 4/6 without skipping; errors equal to thresholds earn no credit. No invented replacement values are used. Original CSV SHA256 is recorded separately from the generated JSON hash, which is not a byte-identical CSV reconstruction.

The original reader can overwrite duplicate identities and the scorer can omit unpredicted datasets. The strict wrapper rejects duplicate/missing/extra composite identities before scoring. It validates schemas, numeric dimensions, fully finite or fully NaN poses, and finite rotation orthogonality/determinant with absolute tolerance 1e-3. Unregistered predictions must use fully NaN poses. GT outlier consistency is verified by authentic metadata hash and audited scene counts at split generation. Missing or invalid scene thresholds fail explicitly.

Training schema: `dataset,scene,image,rotation_matrix,translation_vector`. Submission schema: `image_id,dataset,scene,image,rotation_matrix,translation_vector`. Future submissions must retain the original `(image_id,dataset,image)` ordered sequence; predicted scene and pose fields can change. No predictions are generated. The six-column sample contains 1945 rows in returned reports, but only 73 visible test identities were observed; do not infer hidden test size or train/test interchangeability from placeholders. Primary scoring takes strict five-column local evaluation files, separately from the submission contract.

Limitations: exact deployed Kaggle parity unknown; source revision unknown beyond content hash; sensitivity purity interpretation is explicit; external pretraining overlap unknown; small or degenerate scenes reduce registration reliability. Synthetic correctness tests are software evidence, not benchmark/model performance.
