Verify the cache SHA-256, pinned replay environment, image order and image hashes first. Restore the original mapper options, work directories, thread and seed controls. Make independent logical copies from the same read-only snapshot. Establish unchanged versus pass-through parity with sufficient time for both branches and output export. Compare registration IDs, component assignments, aligned poses and frozen scores with the Phase 4C parity checker.

For a future nonempty approved mask delete every banned pair ID from matches and two_view_geometries in one transaction on the active copy. Verify surviving row hashes, camera/image/keypoint tables and mask membership before and after mapping. Enter directly at incremental_mapping with no pair generation, verification or rematching; disable paths capable of reintroducing connections. Save timings, peak memory and failure receipts for each branch. Restore identities only after predictions are frozen and apply the same evaluator and thresholds. Compare paired per-dataset and aggregate results against the registered baseline before claiming improvement. Haiper's B2 mask is identical to pass-through, so an active run there cannot measure a mask benefit.
