# Common-observation evidence

For each registered camera i and feature index k, project its associated 3D point with that branch's camera and pose and measure Euclidean error in the original image pixels. Use the same immutable feature index in both branches. Changing a model's similarity gauge does not change its projection. Never pair arbitrary 3D point IDs across branches.

For each image let C be the intersection of triangulated feature indices. Record baseline and trial counts, intersection, lost and newly gained observations. Compute d_i = median over C of (trial error minus baseline error). Give cameras equal weight within each side. A trial must reproduce the exact expected membership change, with both sides fully registered in separate models and every other model's membership identical. Require at least 95% of the affected baseline point count, at least 95% of baseline observations per registered image and at least 30 common observations per image. Reject if any d_i exceeds +0.05 px. Accept only if the median d_i on each side is below -0.05 px.

These thresholds are prespecified engineering tolerances, without a claim of statistical calibration. The 5% loss ceiling limits selective survival, 30 measurements avoids tiny medians, and a twentieth of a pixel discourages acceptance on roundoff alone. Six images per side and the sweep tolerances are inherited. Duplicated 3D structure could inflate point counts. The common-feature check limits that failure but cannot exclude it. Splitting a legitimate scene can reduce in-sample reprojection error, even on shared observations, because separate reconstructions have greater freedom. Only prospective paired evaluation tests whether the vetoes protect valid scenes.
