# Model and measurements

Let a vertex denote an opaque input image. A verified pair with n positive inliers has weight log(1+n). On each connected component use the frozen connected Fiedler sweep to minimize cut(A,B)(1/vol(A)+1/vol(B)) with at least six images on each side. Rank one proposal per eligible component by median crossing-edge endpoint neighborhood Jaccard. Use the minimum, with the v2 deterministic tie rule. Remove all A×B pair IDs from both pair tables on a verified copy. The original and at most one trial use identical numerical inputs elsewhere and the published mapper options.

**Why point counts fail.** One track observed in six images and three tracks of length two cover six observations in either case. A point-count ratio can therefore triple at fixed coverage. Rejecting a false cross-scene track may correctly remove an association while its features reappear in separate triangulations. Splitting can also discard genuine measurements, change triangulation thresholds, camera optimization, bundle adjustment or which landmarks survive. Image observations alone do not establish which removed track was false. Separate reconstructions have independent similarity gauges and local landmark identifiers.

**Identity and projection.** Define o=(opaque image, original zero-based keypoint row). Require matching database image ID, camera ID, row count and exact pixel coordinates, unique model membership and bidirectional track backlinks. For each branch r store eᵣ(o)=‖π(Kᵣ,RᵣXᵣ+tᵣ)−x(o)‖₂ in pixels using the optimized branch camera, or NaN for an untriangulated row. A 3D ID is dereferenced only within its own reconstruction. A consistent world similarity leaves projected pixels invariant. Cross-branch pixel residuals can be compared without a pose alignment. [COLMAP observation/track format](https://colmap.github.io/format.html) · [Pinned PyCOLMAP projection binding](https://github.com/colmap/colmap/blob/3.11.1/src/pycolmap/scene/camera.cc)

For image i, let O and T be original and trial observed rows, C=O∩T, L=O∖T and G=T∖O. Report all four counts. For τ=4 px define

    dᵢ = [Σ(o∈C) (min(e₁(o),τ) − min(e₀(o),τ)) + τ |L|] / |O|.

The unit is pixels per original observation. G is reported with zero credit. Removing any original observation costs τ, at least as much as any possible observed deterioration under clipping. Retaining a large number of easy observations cannot offset poor coverage on a different image. Clipping also reduces sensitivity to catastrophic residuals above the cap, a limitation. Define Hᵢ as original rows at or above the per-image 75th percentile of original finite error, including ties.

**Decision.** Require exact replacement of the single fully registered component by its two proposed memberships, with all other model memberships and outlier status preserved. Require at least 30 common observations per registered image. In every image, require |C|/|O| and |Hᵢ∩T|/|Hᵢ| each ≥0.95 and dᵢ≤0.05 px. Each proposed side must have median dᵢ strictly below −0.05 px. Unsupported proposals, invalid exports, a timed-out trial and insufficient common support select the sealed original. Measured regressions reject the split. The implementation distinguishes rejection, abstention and missing original inference. The 95%, 30 and 0.05 values carry forward from v2. The 4 px cap and upper quartile are prospective design choices. No threshold sweep was performed.

**Complexity.** For n≤225 and m edges, dense spectral decomposition is O(n³) with O(n²) space. Connected-sweep validation can take O(n(n+m)) in tied/disconnected cases. Crossing-neighbor intersections cost up to O(mn). Deletion enumerates at most O(n²) pair IDs. After mapping, export visits every input feature of registered images and every track element, O(K+T) expected hash-table work and space for dense residuals plus track validation. Quantiles and medians are computed per image. SQLite copying and digesting scale with numerical database bytes. Matching and nonlinear mapping dominate elapsed time and have no useful dataset-independent wall-time guarantee.
