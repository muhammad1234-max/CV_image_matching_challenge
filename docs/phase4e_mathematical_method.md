# Observation-level measurements

Assign contiguous indices to (opaque image, feature index) and build a symmetric sparse Boolean adjacency A. For a verified link uv compute N(u) intersect N(v) in batches by sparse row multiplication. Each common observation closes an exact cycle; divide summed incidences by three for unique triangles. A match gets at most one participation vote and at most one witness per third image. Two different third images yield internally vertex-disjoint length-two paths for fixed endpoints. Shared endpoints, correlated matching and repetitive texture preclude interpreting these as independent trials.

Compute connected components as track hypotheses. Reject the entire hypothesis as conflicted if any image appears with distinct feature indices. A clean multi-view link belongs to a nonconflicted component with at least three observations. A conflict can propagate along one bad bridge; it does not imply that every member is false. Open wedges are inconclusive because matching is partial. Missing closure is measured by the complement of cycle participation. Record component size of the image graph, number of common neighboring images, Jaccard overlap and original inlier count for each image pair.

For each endpoint image, bin observed coordinates in a fixed 4 by 4 grid normalized by camera width and height. Report occupied cells separately for supported and unsupported links, each out of 16. Coincident features occupy one cell. The JSON retains integer numerators; divide by n verified matches per edge for rates. Ratios describe coverage, not probabilities. No learned combination or pruning threshold was estimated. Boundaries are the original 4D normalized-cut proposals shared by B2. All 454 edges are included.
