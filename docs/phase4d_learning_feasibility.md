# Feasibility of learning

Only Haiper provides a validated Phase 4C numerical graph here. Its two proposed boundaries cannot support learning or an independent validation estimate. The frozen split inventory lists six dev_a datasets in five source groups (heritage_dioscuri repeats) and five dev_b groups. These are potential capture sources, not available labeled boundary examples. Before training, group duplicates by source and image digest, inspect near-duplicate provenance, and exclude ambiguous overlap across folds. Keep dev_b held out for development comparison and confirmation sealed.

If future captures justify training, start with a CPU regularized logistic model on support ratio, neighborhood overlap, boundary cardinality and stability. Build pair labels offline from authorized training membership only. Keep ambiguous/outlier labels separate. Weight by source, report class counts, precision-recall and false-split rate with coverage. Edges sharing photographs cannot serve as independent validation examples. Topology-only supervision cannot resolve the identical-input counterexample. Defer training until independent appearance or correspondence evidence exists across source groups.
