# CPU geometry interface v1

Use `python -m src.novel_model.geometry_graph_v1 reports/phase4b/synthetic_graph.json reports/phase4b/synthetic_manifest.json --method candidate_a_v1 --output decision.json` from the project root. Choose a fresh output path. Omit the method for pass-through. Runtime dependencies are Python, NumPy, SciPy and PyYAML. Profiling also uses psutil. Tests use pytest.

**Input contract.** A strict JSON schema admits only nodes, edges, mode, frame convention, version and digest provenance. Independently supplied manifest pins payload bytes, complete sorted opaque membership, source, configuration and parent. A trusted producer is responsible for physical calibration and direction; no SO(3) test can distinguish a mislabeled R from its inverse by inspecting one matrix. The read-only API rejects duplicate IDs/keys, repeated unordered pairs, self-loops, missing endpoints, noninteger or nonpositive counts, inconsistent rotation masks and invalid matrices. The syntax accepts image_ followed by 4–10 decimal digits and an optional .png. Node order and canonical undirected edges are sorted lexicographically. All cameras, including isolates, must be enumerated. A topology-only field is null. A false validity bit never creates an identity measurement. Validity tolerance is 1e-6 on determinant and max absolute orthogonality error. A rotation is backed by immutable bytes. Ground-truth names and poses have no input fields.

**Boundary proposal.** Within each original component, use log1p(actual inliers), solve the symmetric normalized Laplacian, convert the eigenvector back to generalized coordinates, then sweep all eligible thresholds. Keep each side connected and at least six nodes large. Compute prefix cut costs incrementally. Test connectivity in ascending cost order; lexicographically canonical sides resolve tied feasible costs within 1e-10. Fix eigenvector sign and round coordinates to 12 decimals only for numerically tied sweep ranks. A gap of at most 1e-8 between the second and third eigenvalues causes abstention. Small components, missing weights, and solver failure have explicit reasons. Exactly one cut is considered per eligible component; no recursion.

**Geometry.** R maps source camera coordinates into target camera coordinates. Canonicalizing a reversed pair transposes it. Maximum-weight internal Kruskal trees use only calibrated edges, with descending inlier count (monotonic in log weight) and endpoint tie breaks. Propagate Uj = Rji Ui from the least opaque ID. A distinct internal edge gives closure angle of Ujᵀ Rji Ui. Use the nearest-rank 80th percentile, at least four checks and at most 10° per side. Both sides report independent tree/loop diagnostics. A valid crossing edge predicts Q = Ujᵀ Rji Ui. Geodesic separation uses atan2 of sine from the skew part and cosine from the trace. Changing frame gauges sends every Q to the same left/right rotation of Q and leaves distances invariant.

Greedily select 6–32 crossing edges with distinct endpoints by count and canonical IDs. Compare every observed witness center at radius max(15°, 2(sA+sB)). Split only if the largest consensus count is strictly below half. A tie retains the graph. Unsupported geometry abstains. Greedy matching can miss a larger feasible matching; shared internal tree estimates also induce correlations between distinct witnesses.

**Output contract.** Per-component decisions include ordered nodes, cut, eigenvalues and sweep costs where available, tree edges/orientations/depths, closure residuals, incident camera coverage, crossing transforms, witness edges, distance matrix, all center counts and winning residuals. Early exits identify the missing evidence. Masks are booleans in canonical pair order with input, policy and pair/mask hashes. A whole-boundary split can remove an unmeasured pair *only* because other measured witnesses established a boundary. RETAIN and ABSTAIN both preserve every edge. Mask-enabled code never modifies its input. Use checked_keep_mask to bind returned JSON to the original graph/configuration before a future consumer copies the mask. A SHA-256 digest supplies integrity relative to trusted receipts, not proof of measurement quality. [Pinned configuration](../configs/novel_model/geometry_graph_v1.yaml)
