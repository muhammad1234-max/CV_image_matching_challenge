The final candidate is a one-trial reconstruction-feedback selector (Option A). A graph boundary earns a split only when corresponding 2D observations support it on both sides, difficult features remain represented, and the original camera coverage is preserved. A pre-mapper learner would save mapping time but lacks source-disjoint numerical examples and calibration evidence. The scientific claim under test is that explicit accounting for missing original observations can make a whole-boundary trial more reliable. Its generalization and publication novelty are open.
