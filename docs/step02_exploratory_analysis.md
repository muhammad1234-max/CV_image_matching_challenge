scripts/inspect_dataset.py streams CSV rows, checks exact header and field widths, counts records by dataset/scene/outlier, reports unique IDs and duplicate/conflicting labels via disk-backed SQLite, checks pose dimensions/nonfinite values and rotation orthogonality/determinant, and optionally checks two candidate image layouts. It writes JSON, a scene-count CSV and SVG distribution chart. Inventory produces relative paths, sizes and extensions without reading images. Counts include duplicate rows, explicitly separated from unique image records; malformed rows are flagged. All-NaN poses are counted, not automatically treated as errors because outlier/unregistered conventions differ from malformed poses. Image existence is not image decoding or semantic near-duplicate detection. Inventory is an explicit function; CLI analyzes CSV only.

Synthetic fixtures contain five invented datasets with six records each. These exercise code, not actual competition EDA. Memory use scales with dataset/scene counts, with the image-ID index on disk; no images are loaded. Output directories must be on D: locally. See evidence/step02_tests.txt for actual test results.
