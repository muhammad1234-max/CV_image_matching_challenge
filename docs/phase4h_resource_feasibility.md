# Resource feasibility

The free Stairs VM exposed roughly 11.24 GiB of cgroup memory, initially charged about 9.68 GiB. At capture time the remaining 1,196,421,120 bytes crossed the required 1,206,386,688-byte margin. No cgroup OOM or OOM kill was recorded. Reclaimable file-cache contribution is unknown. Theater/Church had 2,405 seconds remaining against a required 3,000 seconds. It stopped before capture.

Before any future authorization, verify a compatible environment, dataset membership, parent availability, cgroup limit and charge, memory.stat cache breakdown, host availability, swap, GPU capacity, OOM counters and remaining session time after setup. Budget time for checkpoint export. Prefer replay from an authenticated parent. Use the existing margin and stop if preflight fails.
