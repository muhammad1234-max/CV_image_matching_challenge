# Phase 2C provenance and leakage
Local evidence: dioscuri is a scene label in imc2023_heritage and imc2024_dioscuri_baalshamin. This suggests a shared-source candidate, not proof of duplicate image content. Other historical/PhotoTourism name families are uncertain source relationships. License text and image pixels were not included in the returned ZIP, so no actual duplicate claim is made locally.

The new CPU notebook implements Stage A: scene and normalized filename comparisons, relative layout records, license hashes and bounded URL samples from license/source text. Stage B: hash same-size image candidates only where their size appears in different named training datasets; streaming 1 MiB reads. Stage C: 64-bit difference hashes from small EXIF-adjusted grayscale thumbnails, cross-dataset Hamming-distance screening (default <=5). This is a diagnostic screening threshold, not a competition scoring threshold. Similarity is unreviewed and never treated automatically as identity.

Exact matches create must-link dataset components. Perceptual and name candidates remain uncertain and require conservative human review of training images on Kaggle. No thumbnails/source images are packaged. Absence of duplicates does not establish independent sources. Test-image bytes are not read; only visible test paths are used for contract checks, not model selection.

Default overlap budget 120 seconds and 10,000 images; file indexing, hashing and pair loops check a cooperative deadline. A single decoder/filesystem operation may overrun; this is not a hard process kill. One image at a time, JPEG draft and thumbnail resizing; non-JPEG decoding can still allocate one full image. Cache persists in working storage and is reused only for the same path/size/mtime catalog and algorithm version. It is not a cryptographic proof input content is unchanged. Pair screening restarts on rerun; its exact comparisons/total counts and cache coverage are reported. Decode errors and partial coverage block complete claims. A 20,000-candidate cap also makes results partial. Cache and identity mapping are excluded from ZIP.
