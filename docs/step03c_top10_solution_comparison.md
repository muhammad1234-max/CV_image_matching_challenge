# Top10 solution comparison

| Team and competition rank | Evidence and published method | Feasibility |
|---|---|---|
| KaQlN, 7th | run.sh launches main.py with v35.json on training ETs. Its tasks enumerate pairs, determine rotation, run multiscale ALIKED and LightGlue, filter matches and run RANSAC. clustering.py cuts weak edges of a maximum spanning tree. The write-up also describes track refinement. | No submitted notebook version linking that task list, graph parameters, reconstruction variant and checkpoint bytes. NetworkX and pandas implement the graph, but matching and refinement compatibility with the organizer stack remains untested. All-pairs matching costs up to 25,200 comparisons on 225 images before rotation and repeat passes. |
| ymg_aq, 9th | DINOv2 retrieval with top 50 and threshold 0.15, exhaustive below 100 images. Rotation-aware ALIKED and LightGlue at 840, 1280 and 2048 pixels, correspondence crops from DBSCAN, RANSAC and COLMAP camera-model grouping. | The write-up gives inconsistent threshold direction. No pinned submission code, checkpoint bundle, environment lock or license for redistribution was established. Three matching resolutions and CPU mapping preclude a reliable runtime estimate from image count alone. |
| ns64, 1st | Authors identify the best-run configuration and executable. Four retrieval branches feed MASt3R hybrid matching. COLMAP model membership supplies scene clusters. | Strongest configuration attribution. Compiled retrieval and rotary-position extensions and additional weights require a separate environment. Two GPUs supported in the submission launcher. |
