# Selected design v1 — testing a scene boundary with relative rotations

**Decision requested.** Prototype candidate A on CPU after supervisor approval. It adds one decision between ns64 pair verification and incremental mapping. The output unit is a partition of an existing verified component. There is no new matcher, retrieval pass, GPU backbone, or fitted parameter. Fallback C is a separate experiment. Precise equations and thresholds are in phase4a_mathematical_formulation.md and the YAML proposal.

| Interface | Representation | Meaning |
|---|---|---|
| Images | N opaque IDs, node table [N,3] | Neutral-order rank, verified degree, weighted degree. Rank only breaks ties. Keep resolution, intrinsics, distortion model and image digest as typed metadata. |
| Verified graph | int64 endpoint table [E,2], int counts [E], float weights [E] | One canonical edge per verified image pair with the actual post-pruner inlier count. Include isolated cameras. Never construct edges from directory names, reference poses, source groups or diagnostic scene labels. |
| Geometry | float64 [E,3,3], bool [E] validity | Calibrated rotations with explicit source/target camera frames. Missing, planar-only, panoramic-only or ambiguous essential decomposition is masked. No guessed identity rotation. Translation directions are diagnostic only. |
| Optional geometry recovery | per-edge variable [K,2] correspondence indices, [P_i,2] keypoints per image, camera calibration records | First establish whether the exact pinned database exports valid relative poses. Otherwise version a shared CPU recovery adapter using frozen inliers, distortion-aware normalized rays, essential decomposition and positive-depth selection. Exclude edges with fewer than eight usable inliers, fewer than 75% positive depths or median triangulation angle below 1 degree. Freeze solver, numeric version, distortion convention and tie policy before any real use. Ambiguous or unsupported configurations abstain. |
| Decision/output | side labels [N], keep mask [E], reason and counters per component | Identity mask by default. Propagate an accepted boundary into a branch-local mapper input. Multiple output models within a side remain possible. |
| Predictions | frozen CSV schema, one row per original image | World-to-camera rotations [N,3,3] and translations [N,3] for registered cameras, cluster and outlier encoding from original exporter. Internal tree orientations never become submitted poses. |

**Placement.** In snapshots/top10_ns/pipelines/imc2025_pipeline.py the pipeline imports keypoints and matches, calls verify_matches, optionally prunes, then invokes pycolmap.incremental_mapping. Capture the database at that boundary. Preserve camera/image IDs, camera models, priors, initialization rule, mapper options, mapper ordering, number of threads, post-localization policy and export conventions. If the published pipeline is called per preliminary cluster, operate inside each invocation and preserve its outer merge policy. Do not manufacture edges across invocations.

**Mapper contract.** For accepted cuts, enforce the mask in verified geometries, raw match storage and any post-localizer associations used by the experimental branch. Ensure camera initialization consults the same masked graph. Scope localization to the assigned side if it can reintroduce a removed association. Exporter keeps failed registrations as outliers; graph isolation alone is insufficient to label an outlier. Prove that no final model straddles an accepted boundary. If the interface requires per-side mapper calls, identify that as a separate adapter version and run a matched pass-through control. Avoid blanket changes to COLMAP thresholds or reassigning failed cameras to nearest clusters.

**Determinism and failure.** Sort edges and ties by pinned neutral order; choose canonical sweep sides independent of eigenvector sign. Compare tied costs within 1e-10. For repeated second eigenvalues (gap to third at most 1e-8), failed eigensolve, unavailable pose support, small sides or insufficient witnesses keep every original pair and log the reason. Treat non-finite or structurally invalid caches as an invalid run, not an observed no-op. Include raw mask digest, internal closure counts, cross-edge counts before/after endpoint balancing and mapped camera totals. Stage 1 must test rotated/reversed edges and mapper/export parity before score access.

**Cost.** Sparse eigensolve approximately O(I E) sparse products per component for a fixed small number of eigenvectors. All sweep weights can be updated in O(E+N log N); naively checking connectivity at each sweep adds up to O(N(E+N)). At N≤225 accept that CPU bound or verify identical sorted-cost cuts in order until one is connected. Internal trees and ordering O(E log E), residuals O(E), boundary vote O(min(32,E)²). Working memory O(N+E+32²) excluding the read-only database; stream inlier recovery by edge. Thick matching caches or dense all-pairs features would dominate these estimates.

**What this could change.** Only proposals that expose a genuine boundary with internally reliable rotations can benefit. Already separated components are never joined. A component can still be incorrectly split, particularly with bad focal lengths, a long tree, or a real scene with sparse overlap. A negative result distinguishes three causes if retained in the receipts: failure to propose the boundary, insufficient geometric witnesses, or evidence favoring a coherent merge.
