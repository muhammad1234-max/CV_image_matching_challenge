# Minimal integration and resume contract

1. Capture once after verified matching. Export a consistent SQLite backup, logical table digests, image-order and byte hashes, model/config/source/environment pins and exact mapper options. Verify the backup before marking that stage complete.
2. On separate immutable branch copies run unchanged mapping and one frozen candidate trial. Persist each opaque prediction, candidate/mask digest, database audit and per-model point count, membership and reconstruction identity immediately after that branch.
3. At export either save the full sparse reconstruction (cameras, images and points3D with tracks) or save a float array per image indexed by immutable original keypoint row. Store the observed pixel reprojection error in branch camera coordinates using optimized projection and NaN for untriangulated rows. Validate units, array length, index mapping, finite projected values and model membership. Hash every file and bind its branch, source, parent and mask. No cross-branch alignment of 3D point IDs is needed.
4. Persist completed artifacts to durable storage and verify downloaded hashes before disconnecting. Resume at the first missing stage. Run the sealed decision in a fresh inference environment mounting only approved artifacts. Bind the chosen prediction digest and decision reason before administrative identity restoration and evaluation.

Haiper needs zero additional compute to decide this candidate beyond the CPU replay. To study its unreachable residual diagnostics, recover both native sparse exports if they surface; otherwise a future authorized mapper-only replay of each branch from the existing parent could capture measurements for those new realizations. Matching is unnecessary. Validate parity before comparing them to historical results.
