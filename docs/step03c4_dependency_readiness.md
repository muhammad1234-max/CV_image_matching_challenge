The historical environment used CPython 3.11.11, torch 2.5.1+cu121, pycolmap 3.11.1 and verified ASMK/curope extension wheels. The new build context uses the verified migration archive and its original dependency freeze, bundled wheels and three native wheels. The container probe rehashes the mounted inventory, checks CUDA visibility, imports the extensions and published pipeline, parses the selected configuration and checks effective checkpoint paths. These checks have not run in a container. No matching, reconstruction or scoring is part of the probe.
